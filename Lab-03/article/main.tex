\begin{abstract}
This study proposes mining software delivery proxies from public GitHub
repositories using GitHub Actions. Releases, commit timestamps and workflow
runs support alternative operational definitions of DORA metrics. Manual
annotation and sensitivity analysis will assess how these definitions affect
the interpretation of delivery performance. This preliminary version presents
the research motivation and hypotheses; no empirical findings are reported.
\end{abstract}

\begin{resumo}
Este estudo propõe minerar proxies de entrega de software em repositórios
públicos do GitHub que utilizam GitHub Actions. Releases, datas de commits e
execuções de workflows sustentam definições operacionais alternativas das
métricas DORA. A validação manual e a análise de sensibilidade avaliarão como
essas definições afetam a interpretação do desempenho de entrega. Esta versão
preliminar apresenta motivação e hipóteses, sem relatar resultados empíricos.
\end{resumo}
