**Como ler o G2.** A curva preta é a distribuição t com 28 graus de liberdade que a estatística dos dois testes segue quando H₀ é verdadeira; a região hachurada reúne os 5% de valores mais extremos (|t| > 2,05, metade em cada cauda, porque o teste é bicaudal). No exemplo, Pearson obteve t = 3,48 (p = 0,0017) e Spearman t = 2,58 (p = 0,0155): ambos caem na região de rejeição, e a área colorida além de ±t é o p-valor — a probabilidade de obter uma estatística pelo menos tão extrema **se H₀ fosse verdadeira**, e não a probabilidade de H₀ ser verdadeira. A área cinza, obtida embaralhando os próprios dados, mostra que para o Spearman a aproximação t é fiel, enquanto para o Pearson a distribuição real sob H₀ é irregular, dominada por poucas classes muito grandes — um primeiro sinal de que o p-valor do Pearson pode ser pouco confiável com dados tão assimétricos.
